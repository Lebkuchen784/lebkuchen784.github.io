Core Features

Secure Authentication

Built-in JWT token management (HTTP-Only), encrypted passwords, and secure endpoint access using Spring Security.

Organization Management

Business owners can seamlessly register, manage their organizations, and search through the database.

Automated Emails

Integrated email service for sending welcome messages to the business owners and appointment confirmations to their clients.

Built with modern tech

Java 21 Spring Boot 3 Hibernate & JPA PostgreSQL JUnit 5 & Mockito HTTP-Only JSON Web Tokens

Learning Journey

Building this project was fun but also frustrating at times. I struggled with incorporating JWT Authentication into Spring Security, the amount of boilerplate code was... quite something and understanding how the Security Filter worked took quite a bit of time. Making sure I properly handled HTTP-Only cookies to prevent XSS attacks was important to me in order to provide the most secure authentication implementation that I could for this project scope. On top of that, coming from a pure backend background, working with the frontend felt alien at times. It took me some time to properly understand how to pass data between the UI and my controllers, and getting comfortable with HTML, JavaScript, and Thymeleaf involved plenty of trial and error.
